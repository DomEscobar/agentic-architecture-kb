# Evaluation Consulting Playbook

## Engagement sequence

1. Intake and risk boundary.
2. System/data/evaluator inventory.
3. Reproduce current baseline.
4. Validate tasks, oracles and judges.
5. Build failure taxonomy and slice map.
6. Design minimum eval architecture and ownership.
7. Establish offline regression and promotion gates.
8. Establish shadow/canary/rollback.
9. Run adversarial readiness review.
10. Hand over artifacts, unresolved evidence and review dates.

## Definition of consulting-ready

An answer states assumptions, components/data flow, fit, failure detection,
offline/replay/online evaluation, latency/cost/security/maintenance, rollout and
rollback, alternatives and their winning conditions, confidence, freshness and
unresolved questions.

Separate observation, inference and recommendation. Framework features are not
proof of metric validity. Missing field evidence stays an explicit validation
task. Use the templates under `docs/templates/`; create canonical Case Records
only from real evidence and never fabricate consulting outcomes.
